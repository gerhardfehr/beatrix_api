\begin{abstract}
\noindent
This chapter presents ESL 2.2's empirical validation: N=115 scientific claims across Physics (n=25), Economics (n=28), Behavioral Economics (n=27), and two author corpora (Shiller n=15, Fehr n=20). ESL achieved 100\% classification accuracy---all claims with $K \geq K_{\text{stable}}$ were confirmed; all claims with $K < K_{\text{stable}}$ were falsified or contested. Empirically derived thresholds: Physics (0.79), Economics (0.76), Behavioral Economics (0.60). This validation upgrades ESL from T4 (Proposal) to T2 (Empirically Validated), with earned $K = 0.84$.

\vspace{0.5em}
\noindent\textbf{Keywords:} Empirical validation, classification accuracy, K-thresholds, replication, predictive validity
\end{abstract}

\subsection{The K-Metric Advantage}

High methodology quality produces systematic K-metric advantages:

\begin{enumerate}
    \item \textbf{Triangulation} ensures $E \approx B$: When lab, field, and natural experiments converge, evidence matches claims.

    \item \textbf{Cumulative research} calibrates expectations: Building on validated findings prevents overclaiming.

    \item \textbf{Axiomatic models} constrain claims: Formal predictions (Fehr-Schmidt utility) are falsifiable---authors cannot HARKing.

    \item \textbf{No deception} reduces noise: Clean designs produce cleaner evidence.
\end{enumerate}

\begin{examplebox}[title={Fehr \& Gächter (2000): Altruistic Punishment}]
\textbf{M-Score Components}:
\begin{itemize}
    \item TRI = 1.0 (Lab + one-shot + stranger matching + real stakes)
    \item NOD = 1.0 (No deception)
    \item THF = 1.0 (Game-theoretic model)
    \item APP = 1.0 (Complete z-Tree code in appendix)
    \item INC = 1.0 (Performance-based payment)
    \item STD = 1.0 (z-Tree)
    \item REP = 1.0 (Multiply replicated)
\end{itemize}

$M = 1.00$ (Gold Standard)

\textbf{Replication Outcome}: 100\% across 15+ independent replications worldwide.
\end{examplebox}

\subsection{Implications for ESL Assessment}

When assessing claims from high-M domains:

\begin{itemize}
    \item Higher B-values are justified---strong claims can be backed by strong methods.
    \item K-thresholds can remain stable---methodology ensures evidence matches claims.
    \item Overclaiming is rare---structural safeguards prevent it.
\end{itemize}

When assessing claims from low-M domains:

\begin{itemize}
    \item Skepticism is warranted regardless of B-value.
    \item Even ``modest'' claims ($B = 0.60$) may overclaim if $M < 0.30$.
    \item M-Score should be checked before trusting K-score.
\end{itemize}

\begin{warningbox}[title={The Domain Calibration Principle}]
A $K = 0.75$ in a high-M domain (behavioral economics) indicates stronger epistemic warrant than $K = 0.75$ in a low-M domain (social priming). The M-Score provides context for K-score interpretation.
\end{warningbox}
