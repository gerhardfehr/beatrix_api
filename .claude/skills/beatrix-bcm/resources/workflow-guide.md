# PHASE 1: DIAGNOSE

**Ziel**: Ausgangslage verstehen

## 1.1 Zielverhalten definieren

```
┌─────────────────────────────────────────────────────────────────────┐
│ FRAGEN:                                                             │
│                                                                     │
│ □ Was ist das gewünschte Verhalten?                                │
│   Beispiel: "Mitarbeiter nutzen Treppe statt Aufzug"               │
│                                                                     │
│ □ Was ist das aktuelle Verhalten?                                  │
│   Beispiel: "90% nutzen Aufzug, 10% Treppe"                        │
│                                                                     │
│ □ Wie gross ist die Verhaltens-Lücke (Δ)?                          │
│   Beispiel: Δ = 80% (Ziel: 90% Treppe)                             │
│                                                                     │
│ □ Ist das Verhalten beobachtbar/messbar?                           │
│   Beispiel: Ja, via Sensoren/Zählung                               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 1.2 Zielgruppe definieren (σ)

```
┌─────────────────────────────────────────────────────────────────────┐
│ FRAGEN:                                                             │
│                                                                     │
│ □ Wer soll das Verhalten ändern?                                   │
│   Beispiel: "Büromitarbeiter, 25-55 Jahre"                         │
│                                                                     │
│ □ Ist die Gruppe homogen oder heterogen?                           │
│   Beispiel: Heterogen (verschiedene Abteilungen)                   │
│                                                                     │
│ □ Gibt es relevante Segmente?                                      │
│   Beispiel: Segment A (jung, sportlich), Segment B (älter)         │
│                                                                     │
│ □ Wer sind Key Influencer in der Gruppe?                           │
│   Beispiel: Teamleiter, beliebte Kollegen                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 1.3 Kontext erfassen (ρ)

```
┌─────────────────────────────────────────────────────────────────────┐
│ KONTEXT-DIMENSIONEN:                                                │
│                                                                     │
│ □ PHYSISCH                                                         │
│   - Wo findet das Verhalten statt?                                 │
│   - Welche Infrastruktur existiert?                                │
│   - Gibt es physische Barrieren?                                   │
│                                                                     │
│ □ SOZIAL                                                           │
│   - Welche sozialen Normen gelten?                                 │
│   - Was tun "die anderen"?                                         │
│   - Gibt es sozialen Druck?                                        │
│                                                                     │
│ □ INSTITUTIONELL                                                   │
│   - Welche Regeln/Policies existieren?                             │
│   - Gibt es Anreize/Sanktionen?                                    │
│   - Wer hat Entscheidungsmacht?                                    │
│                                                                     │
│ □ KULTURELL                                                        │
│   - Welche Werte sind relevant?                                    │
│   - Welche Narrative existieren?                                   │
│   - Gibt es kulturelle Tabus?                                      │
│                                                                     │
│ □ TEMPORAL                                                         │
│   - Wann findet das Verhalten statt?                               │
│   - Gibt es Zeitdruck?                                             │
│   - Langfristig vs. kurzfristig?                                   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

```

# PHASE 2: ANALYSE

**Ziel**: Nutzen-Struktur verstehen (INU, KNU, IDN)

## 2.1 INU-Analyse (Individueller Nutzen)

Für jede FEPSDE-Dimension: **Gain (G)** und **Pain (P)** bewerten.

```
┌─────────────────────────────────────────────────────────────────────┐
│ FEPSDE-ANALYSE                                                      │
│                                                                     │
│ Dimension    │ Gain (G)           │ Pain (P)           │ Δ = G-λP  │
│ ─────────────┼────────────────────┼────────────────────┼────────── │
│ FINANCIAL    │ Spart Geld?        │ Kostet Geld?       │           │
│              │ Score: ___/10      │ Score: ___/10      │ ___       │
│ ─────────────┼────────────────────┼────────────────────┼────────── │
│ EMOTIONAL    │ Fühlt sich gut an? │ Unangenehm?        │           │
│              │ Score: ___/10      │ Score: ___/10      │ ___       │
│ ─────────────┼────────────────────┼────────────────────┼────────── │
│ PHYSICAL     │ Bequem? Gesund?    │ Anstrengend?       │           │
│              │ Score: ___/10      │ Score: ___/10      │ ___       │
│ ─────────────┼────────────────────┼────────────────────┼────────── │
│ SOCIAL       │ Status? Ansehen?   │ Peinlich?          │           │
│              │ Score: ___/10      │ Score: ___/10      │ ___       │

│ ─────────────┼────────────────────┼────────────────────┼────────── │
│ ECOLOGICAL   │ Umweltfreundlich?  │ Umweltschädlich?   │           │
│              │ Score: ___/10      │ Score: ___/10      │ ___       │
│ ─────────────┴────────────────────┴────────────────────┴────────── │
│                                                                     │
│ λ (Loss Aversion) = ___ (typisch: 2.0-2.5)                         │
